# Task Manager — OOP Project

Конзолно приложение за управление на проекти и задачи, написано на C++.

## Функционалности
- Управление на проекти (CRUD)
- Управление на задачи с приоритети и статуси
- Назначаване на изпълнители
- Тагове, филтриране и сортиране
- История на промените (ChangeLog)

## Компилиране
```bash
g++ -std=c++17 src/*.cpp -I include -o TaskManager
```
